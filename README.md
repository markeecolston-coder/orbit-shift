# Orbit

The game source, assets, tests, release documentation and package files are in **[orbit/](orbit/)**.

- [Play Orbit Shift](https://markeecolston-coder.github.io/orbit-shift/)
- [Game documentation](orbit/README.md)
- [Cloud tests and Android builds](https://github.com/markeecolston-coder/orbit-shift/actions)

In a cloud terminal: `cd orbit`, then `npm ci` and `npm run dev`.

GitHub workflow files and the Codespaces launcher stay at repository root so GitHub can discover them. All build commands run inside `orbit/`.
